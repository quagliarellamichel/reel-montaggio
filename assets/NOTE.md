# Font Plus Jakarta Sans

`PlusJakartaSans-Bold.ttf` è in realtà il font variabile `PlusJakartaSans[wght].ttf`
del repo ufficiale google/fonts (non esiste una versione statica "Bold" separata
in quella cartella): https://github.com/google/fonts/tree/main/ofl/plusjakartasans

Rinominato così solo per comodità del path passato a `drawtext=fontfile=...`.
ffmpeg/libass renderizzano il peso di default del font variabile (non il Bold
esplicito) — accettabile per l'hook testuale del reel.
